# Microservicio Actividad Versiones

Microservicio desarrollado en Spring Boot enfocado en la gestión de versiones y endpoints básicos de prueba.

---

## Ejecución del Proyecto

Puedes ejecutar la aplicación desde la terminal posicionándote en la raíz del proyecto:

### Con Maven Wrapper:
```bash
./mvnw spring-boot:run
```

El servicio iniciará por defecto en el puerto 8080.

---

Todos los endpoints comparten la ruta base /api/v1.

GET: /api/v1

POST: /api/v1
